How it works

Self-host in three steps

Install

Run curl -fsSL https://kortix.com/install | bash on a laptop, VPS, VPC or on-prem host. No managed service required.

Connect

Bring your own model keys and connect 3,000+ apps or any MCP, OpenAPI, GraphQL or HTTP API. Credentials stay brokered server-side.

Run and review

Every session boots an isolated Linux machine. Work lands as a change request a human reads as a diff — deny by default.

Quick FAQ

Is Perplexity Computer open source?+

No. Perplexity Computer is a closed, cloud-only product available to Perplexity Max subscribers. There is no self-hosted edition. Kortix is the open-source alternative: read, fork and modify the code.

What is the best open-source alternative to Perplexity Computer?+

Kortix. It is the open-source AI Management System and the leading open-source alternative to Claude Cowork and ChatGPT Work: one git repo you own, 3,000+ connectors, any model with your keys, and a change request a human reviews before work lands.

Can I run a Perplexity Computer alternative locally?+

Yes. Kortix self-hosts on a laptop, a VPS, your VPC or on-prem, and so do OpenClaw, Eigent, AnythingLLM and Vellum. See the self-hosting guide.
