How it works

## Self-host in three steps

### Install

Run `curl -fsSL https://kortix.com/install | bash` on a laptop, VPS, VPC or on-prem host. No managed service required.

### Connect

Bring your own model keys and connect 3,000+ apps or any MCP, OpenAPI, GraphQL or HTTP API. Credentials stay brokered server-side.

### Run and review

Every session boots an isolated Linux machine. Work lands as a change request a human reads as a diff — deny by default.

Kortix is open source (Elastic License 2.0) — self-host, read and modify the code. [Kortix on GitHub](https://github.com/kortix-ai/suna).
